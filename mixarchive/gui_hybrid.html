01Add sources

A channel or playlist becomes its own collection. Single videos go into YouTube picks.

    02Update

    Checks each collection for new uploads, downloads them, splits mixes into tracks, tags and levels them. Finished work is skipped, so it's safe to run any time.

    collectiondownloadedtracks

    03Sync to rekordbox

    playliston diskin rekordboxto add

    04Analyze

    This step happens in rekordbox. mixarchive keeps a playlist of everything it added that hasn't been analyzed.

    1. In rekordbox, open mixarchive › Not analyzed yet.
    2. Select all tracks (⌘A).
    3. Right-click › Analyze Track. When it's done, press Recheck here.

    05USB stick

    Also in rekordbox: sync the mixarchive playlists you want onto the stick. Analyze first so the players get beatgrids.

    playlisttracksnot analyzedsize
